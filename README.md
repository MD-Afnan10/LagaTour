# Laga Tour 🏖️

Laga Tour is a social platform for travelers to share complete tour plans, discover destinations on an interactive map, and connect with other travelers to plan trips together.

## Features

### Social Feed
- Share travel photos and videos
- Write captions or short travel stories
- Like, comment, share, and save posts

### Smart Interactive Map
- Displays tourist destinations shared by the community
- Shows places where users have already traveled
- Explore destinations directly from the map
- Clicking a location opens related tour plans

### Complete Tour Plan Sharing
Users can share their complete travel plan including:
- Starting location
- Destination
- Transportation used
- Accommodation details
- Places visited
- Duration of the trip
- Expense breakdown
- Total budget
- Travel tips
- Related photos and videos

### Search & Filter System
Search and filter tour plans based on:
- Destination
- Budget
- Trip duration
- Transportation
- Travel type (Solo, Friends, Family, Couple)
- Season

### Community Interaction
Users can:
- Like tour plans
- Comment on tour plans
- Share posts
- Save favorite plans
- Follow other travelers

### Traveler Score & League System
- Users earn points based on their activity
- High-quality tour plans receive higher scores
- Total points determine the user's travel league
- Example leagues: Explorer, Adventurer, Traveler, Expert, Legend

### AI Media Verification
- AI checks uploaded photos and videos to determine whether they are related to the shared travel destination
- Helps reduce unrelated or fake uploads and improve content quality

### Group Trip Planner
Users can create upcoming group tours by sharing:
- Destination
- Travel date
- Estimated budget
- Maximum members
- Transportation
- Accommodation plan
- Trip itinerary

Interested users can:
- Request to join
- Be accepted or rejected by the organizer
- Participate in planning

Each group includes:
- Shared itinerary
- Budget planning
- Checklist
- Group chat

### Personal Messaging System
Users can privately message each other to:
- Ask questions about shared tour plans
- Get travel advice
- Discuss accommodation or transportation
- Contact group trip organizers

### Notifications
Users receive notifications for:
- Likes
- Comments
- Messages
- Follow requests
- Group join requests
- Group updates

### Community Rating System
Users can rate:
- Tour plans
- Budget accuracy
- Travel experience
- Trip organizers

Higher-rated plans become more visible.

### Personal Dashboard
Users can view:
- Total trips shared
- Saved plans
- Upcoming trips
- League and points
- Travel statistics

### Admin Panel
Admins can:
- Manage users
- Remove spam or fake content
- Moderate reports
- Review AI-flagged media
- Monitor platform statistics

### AI Tour Package Builder
A tour package builder that creates packages from given resources.

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React.js, HTML, Tailwind CSS |
| Backend API | Node.js |
| Database | MySQL |
| Authentication | Firebase |
| Maps | Google Maps API / OpenStreetMap (Leaflet) |
| Real-time Chat | Socket.io |
| Notifications | Firebase Cloud Messaging |
| Image Storage | Firebase Storage |
| AI | Gemini API |
